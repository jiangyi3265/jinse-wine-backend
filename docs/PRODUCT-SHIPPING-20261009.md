# 商品运费模板关联

## 配置入口

- 管理端「运费模板」维护模板名称、包邮门槛、首件运费、续件运费、续件数量及启用状态。
- 「商品管理 → 新增 / 修改 → 运费模板」选择启用中的模板，可清空选择。
- 未选择模板，或绑定的模板已停用时，使用编号最小的启用模板。
- 被商品引用的模板不能删除；已绑定的停用模板允许在编辑商品其他字段时保留。

## 计费规则

- 所有金额以整数分计算，后台以元输入。
- 配送：首件运费 + 向上取整((件数 - 1) / 续件数量) × 续件运费。
- 优惠后商品金额达到模板包邮门槛时免运费；门槛为 0 时始终包邮。
- 购物车中同一有效模板的商品合并计件、合并判断包邮；不同模板分别计费后相加。
- 购物车优惠按各模板组商品金额比例分摊，保留到分，分摊总额等于订单优惠金额。
- 门店自提运费为 0。
- 商品详情显示未使用优惠券时的运费预览；结算按服务端实际优惠后的报价显示。
- 下单时重新计算并保存 shipping_cent；已创建订单沿用原运费快照。

## 接口与迁移

- 商品目录管理字段：`shippingTemplateId`。
- 商品运费预览：`GET /mini/products/{code}/shipping-quote?quantity=1&skuCode=`，匿名只读。
- 单品报价：`POST /mini/orders/quote`。
- 购物车报价：`POST /mini/orders/cart/quote`，会员鉴权，无订单、库存、优惠券写入。
- 购物车提交：`POST /mini/orders/cart`，与报价共用计算逻辑。
- 数据库：`biz_product.shipping_template_id`，可为空，索引 `idx_product_shipping_template`。
- 可重复执行迁移：`sql/business-shipping-template-upgrade.sql`；完整迁移也包含该字段。
