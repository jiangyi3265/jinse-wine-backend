# 商品分类独立管理

入口：“业务管理 → 商品分类”。先添加分类，再在“商品管理 → 新增/修改商品”中选择分类。商品搜索也改用分类选择框。

分类包含名称、自动编码、排序、启停、备注和商品数量。名称唯一且最多 64 字；停用分类不能新分配给商品，已有商品保留关联。改名同步商品名称字段，兼容当前小程序按分类名筛选；删除前校验全部商品引用，引用存在时拒绝删除。

数据结构：`biz_product_category`，以及 `biz_product.category_id`。已有分类文字在迁移时自动归并，空白分类归入“未分类”。接口写商品时只接受有效分类 ID，并由后端写入对应名称；前端不能靠手工填写分类文字绕过关联校验。分类行锁协调改名、删除和商品关联写入，避免删除与绑定竞争产生失效引用。

升级文件：`sql/business-product-category-upgrade.sql`；新库的完整迁移和菜单脚本也已同步。权限为 `business:productCategory:list/query/add/edit/remove`，按原商品权限逐项迁移；分类选项读取复用商品操作权限。

菜单编号按数据库现有记录自动分配。首次上线遇到原账号管理菜单编号冲突后，已按发布前的角色授权备份恢复冲突菜单权限，再将分类操作移到新的分类父菜单；原账号菜单保持原状。最终线上分类菜单为 3155，开发库可有不同 ID，业务代码不依赖该编号。
