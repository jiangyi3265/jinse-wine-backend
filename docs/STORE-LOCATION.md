# 门店地址解析与距离排序

## 管理端

门店新增、编辑只填写省市区和详细地址，不展示或接收经纬度输入。后端保存前调用腾讯位置服务地理编码 API，保存 GCJ-02 坐标；地址改变或原记录没有有效坐标时重新解析，地址未改变且已有坐标时复用。接口忽略客户端传来的经纬度，防止绕过地址解析。

解析失败、返回地区不一致、可靠度低于 7 或精度级别低于 9 时，不保存此次修改，提示补充街道、门牌号或建筑名称。原记录不变，不写入行政区中心或 0,0。地图请求总超时 5 秒，不在异常消息中返回请求 URL 或凭据。

## 开通与配置

1. 登录 https://lbs.qq.com/dev/console/application/mine，按提示完成开发者注册/认证。
2. 应用管理 → 我的应用 → 创建应用 → 添加 Key，启用 WebService API。
3. 如启用 IP 白名单，加入生产服务器出口 IP（目前服务器为 124.222.244.144，若经过 NAT 以真实出口 IP 为准）。
4. 后端环境变量配置 `TENCENT_MAP_KEY`；若启用 SK 签名校验，同时配置 `TENCENT_MAP_SK`。随后重启 Java 服务。
5. 也可在受保护的外部 Spring 配置文件中填写 `store.geocoding.tencent-key` 和 `store.geocoding.tencent-sk`。不要写入小程序或管理端静态代码。

免费额度、地理编码权限和调用限制以腾讯控制台为准。小程序 AppSecret 不能替代地图 Key。参考：https://lbs.qq.com/service/webService/webServiceGuide/webServiceGeocoder

## 小程序

进入兑换网点页申请当前位置，使用 GCJ-02 坐标计算直线距离并从近到远排列，显示米/公里。地区和关键字筛选后仍按距离排序，没有有效门店坐标的记录排在末尾。定位拒绝或失败时保留门店浏览，显示默认顺序和开启定位入口；点击可进入微信授权设置后重试。当前位置不上传后端。

距离不是驾车/步行路线长度，实际路程以导航为准。H5 浏览器位置从 WGS-84 转换到 GCJ-02 后参与计算。原有门店坐标不会被批量猜测或覆盖，无效地址需要门店运营人员补全后保存。
