# 门店核销复核（2026-10-06）

## 本次缺陷与修复

- 核销页曾把顾客奖品插入核销员个人奖品缓存；个人奖品刷新会移除顾客奖品。现查询结果使用页面独立状态，确认成功后保留已核销状态。
- 失败查询曾可能继续显示缓存中的旧奖品。现开始查询、修改输入、切换类型均清除旧操作；异步请求按查询序号判断，只接受最新响应。
- 核销提交和确认弹窗期间锁定扫码、类型切换和查询操作；未知结果重试保留同一请求号，已核销不能二次提交。
- 后端原来只在确认阶段限制奖品门店；现在查询文字兑换码和官方码短场景值时也检查发放时的门店范围，越权查询返回 403，不返回领取人资料。不限门店奖品仍能正常查询。
- “抽奖奖品”标签更名“实物奖品”，覆盖抽奖与积分兑换来源。“今日核销”原本展示最近最多 100 条记录数，现改为“最近奖品核销”，避免误报当日统计。
- API 模式 H5 扫码按钮打开手工录入，微信小程序继续调用原生扫码。
