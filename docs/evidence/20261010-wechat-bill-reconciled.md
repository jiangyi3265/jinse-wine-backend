## 复核入口

交付源码和部署包均含 `bin/audit-wechat-existing-payments.py`。在当前 Linux 生产服务器用能够读取服务环境和私钥的运维账号运行 `python3 bin/audit-wechat-existing-payments.py`，需要 Python 3、`cryptography`、MySQL 客户端及既有 `marathon.service`。脚本从实际 Java 进程读取配置，仅允许本机 `jinse_wine` 数据库，不输出密钥；最多查询 100 条既有支付或退款，超过上限会明确拒绝，避免误报部分对账为完整成功。

脚本只执行现有单号查单、账单 GET/下载、数据库 SELECT，并保存私有文件及脱敏回执；没有发起支付/退款/转账/消息的代码。根据已支付日期和官方退款成功日期查询账单；某日尚未有下载链接时不会标记该账单对账成功。可由运维通过宝塔脚本运行，不能把含配置的环境或私钥粘贴到客户端代码。
