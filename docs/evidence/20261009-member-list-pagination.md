# 会员历史列表、奖品二维码与 Web 隐藏入口

核对日期：2026-10-09。代码已部署，微信开发版本已上传；未据此宣称正式发布或全部 13 模块验收。

## 实现范围

- 订单、抽奖、积分、实物奖品、现金红包、佣金、奖品核销和商城自提核销共 8 类接口支持可选 `pageNum/pageSize`，返回 `rows/total/pageNum/pageSize`。每页默认 20、最大 100；非法参数及状态返回具体中文校验信息。
- 所有查询使用服务端登录会员，核销历史仍校验核销员及门店权限；商城自提历史还限制当前绑定门店。稳定按主键倒序查询，原始 100/200 条截断已从完整历史接口移除。
- 不带分页参数的旧小程序仍收到完整数组。推广概览中的 100 条只是预览，完整历史使用新增 `/mini/promotion/records`；小程序概览仅显示最近 3 条并提供“全部明细”。
- 订单状态和奖品状态在 SQL 分页前筛选；“待收货”兼容 `shipping/receiving`。奖品补充“已失效”页签，过期数量以当前后端状态计数。
- 页面显示完整匹配数量及翻页，处理末页删除、网络错误重试及快速切换请求次序。个人中心奖品数量使用完整 `total`，不把第一页长度当成总数。
- 只有当前展开的待兑换奖品请求核销二维码，首项默认展开；再打开其他奖品时按需请求并缓存。失败保留文字兑换码，允许重新生成；已兑换或已失效奖品不显示核销二维码。
- Web 端动态路由排除 `business/content/index`，侧栏/搜索无入口；旧 `/business/content` 与 `/business/miniContent` 返回首页。数据库隐藏标记和首页入口的既有设置保留。

## 页面码填写

“获取小程序页面小程序码”中的页面路径填写 `pages/index/index` 可进入首页；商城为 `pages/shop/index`、抽奖入口为 `pages/scan/index`、核销入口为 `pages/verification/index`。页面路径无需域名或开头 `/`。

页面入口码不携带每瓶独立的中奖结果。独立活动码仍须从运营后台按批次生成/导出，普通链接前缀 `https://jiuyekl.oksja.cn/qr/lottery/`，跳转 `pages/scan/index`，前缀占用选“是”；公众平台若要求已发布页面，需使用已发布版本或版本管理中的体验码进行相应阶段验证。
