# 后台图片上传与表单生命周期复核

## 发现及修复

抽奖奖项弹窗未销毁上传组件，关闭弹窗后继续编辑另一奖项时，旧文件上传回调仍可能写入当前表单。通用商品/门店/兑换表单在关闭过渡或记录切换时也需要立即失效旧请求。

统一上传组件新增表单活动状态及上下文标识：关闭、换记录、卸载时先使旧回调失效，再取消上传并释放本组件持有的保存锁。回调核对文件 uid，旧成功/失败回调不能写入新记录、清除新上传锁或弹出错误。上传接口与 MinIO 存储继续使用原配置。

## 验证

运行管理端 `node --test tests/image-upload-lifecycle.test.mjs`，6 项全部通过。测试执行真实 Vue 组件脚本和响应式监听，模拟 Element Plus 网络回调，不请求生产上传接口：

1. 关闭表单后忽略迟到成功与失败。
2. 切换记录后旧上传不能覆盖新记录，也不能提前释放新上传锁。
3. 取消上传同步触发错误回调时不显示虚假的上传失败。
4. 多组件同时上传，卸载只释放自身的锁，计数不会负数。
5. 网络失败或响应格式异常保留原图，随后可重试；重复成功只更新一次。
6. 禁用、非法类型、超限、重复上传不多占保存锁。

管理端 `vite build` 成功，2462 个模块。上述自动化未运行真实浏览器的慢网上传场景；先前 MinIO 实际上传证据见 `20261006-public-media-url.md`。
