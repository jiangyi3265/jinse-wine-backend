## 编码

商品、门店、优惠券模板、积分兑换项、商品规格和系统岗位的新增编码由后端生成。表单只读显示“保存后由系统自动生成”，不要求填写、不提交人工编码。更新接口保留原编码；SKU 按所属商品和 skuId 找回原编码，防止修改编码后历史订单失去关联。新建接口返回生成的业务编码，列表刷新后可见。

已有订单号、抽奖码、核销请求号仍由原业务流程生成。积分规则键、内容键和权限字符是程序识别规则的配置键，不是自动编号，不能随意重新生成。

## 关联选择

本地关联选项走 `/business/options/{owner}/{field}`，按使用表单的权限及门店数据范围查询，接口只返回值、名称及状态。支持名称搜索、分页、指定值回显，避免只取前 200 条造成漏选。新绑定默认显示启用记录；历史失效项保留引用并显示不可用提示。

- 门店所属部门；兑换项券模板及兑换门店；核销员所属门店。
- 订单、奖品、核销记录中的会员/门店/奖品查询条件及名称显示。
- 首页精选商品；运营工作台商品、奖项门店、奖项券模板及社群活动券模板。
- 微信小店商品和规格、快递公司、退货地址、小店名称、订阅模板及企业微信客户群，使用 `/business/platform-options/{kind}` 从对应平台读取名称；列表可刷新和翻页。

平台授权或后端凭证缺失时明确显示错误，保留原配置，不生成虚构选项。视频号 Finder、Feed ID、Nonce ID 属于微信入口/校验参数，现有接口未提供可列举的来源，仍保留对应配置项；不会将这些参数误当成本地数据库外键生成。

## 图片上传

商品、门店、积分兑换、小程序内容、品牌/首页配置、客服及社群二维码、抽奖实物图片均使用上传按钮。支持预览、更换、移除、失败重试；失败时保留原图，上传期间禁止保存。统一调用已有 `/common/upload`，优先保存服务端返回的公开访问 URL，继续使用线上 MinIO 存储。支持 PNG/JPG/GIF/WEBP，前端最大 5 MB。

微信小店发布 JSON 中的素材 ID 是平台素材标识，并非本站图片地址，仍按微信小店资料接口要求处理。
