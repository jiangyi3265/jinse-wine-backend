# 微信登录后保存会员昵称与头像

微信 code2session 只提供身份凭据，不返回昵称、头像。本次接入微信头像选择按钮 chooseAvatar 与 nickname 输入框，由用户确认资料后保存，不使用已无法获取真实资料的 getUserProfile，也不将通用“微信用户”自动覆盖到已有会员。

## 操作流程

登录成功后，资料缺失的会员会看到“完善会员资料”弹层。已登录但资料缺失的老会员，在加载个人中心时也会收到提示。同一运行会话每位会员只提示一次，可跳过后在“我的 → 个人资料”填写。

1. 用户选择微信头像和昵称。
2. 点击“保存资料”，将微信临时头像文件上传至 `/mini/me/avatar`，保存服务器可访问的图片地址到 `biz_member.avatar`。
3. 使用 `/mini/me` 更新同一会员的 `biz_member.nickname`，服务器依据 Bearer 会话识别会员，不信任客户端提交的会员 ID。
4. 个人中心头像和昵称同步更新；以后登录从服务器读取资料，后台会员管理也使用同一份数据。

头像与昵称沿用现有两个保存接口：头像上传成功、昵称保存失败时，已上传头像仍保留，弹层提示错误，重试只保存昵称。取消选择不提交数据。昵称表单使用提交事件读取微信填写值，补充失焦同步；个人资料编辑页同步修复。
