# 财务报表中文显示

8 类报表在 CSV 输出层转换业务枚举，不修改数据库状态代码或流转逻辑。编号、交易号、名称、金额、日期等原始业务数据保持原样，CSV 继续使用 UTF-8 BOM 和公式注入转义。

| 报表 | 中文转换字段 |
| --- | --- |
| 销售订单 | 订单状态、履约方式 |
| 商城退款 | 业务状态、资金渠道状态 |
| 佣金明细 | 佣金状态、是否待追偿 |
| 佣金提现 | 提现状态 |
| 抽奖记录 | 结果类型 |
| 核销记录 | 核销状态（抽奖奖品、商城自提） |
| 销冠奖励 | 发放状态 |
| 微信小店退款 | 平台售后状态、对账状态 |

按报表区分同名状态：例如 pending 在订单中为“待支付”，退款和提现中为“待审核”，佣金中为“待结算”。空渠道状态显示“未发起”，其他空枚举显示“未记录”；新出现的未识别代码显示“未知值（待核对）”，不误判成成功。中文历史状态保留。

管理端下载文件名使用中文报表名称及日期范围；后端响应通过 RFC 5987 filename* 支持中文文件名。已下载的旧文件须重新导出。

实现：BusinessReportLabels.java、BusinessExtensionController.java、管理端 api/business/extension.js。源代码与隔离发布目录同步；发布包不含待地图 Key 的地址解析改动。

前后端生产构建通过，Maven 跳过测试；未新增或运行自动化测试。
